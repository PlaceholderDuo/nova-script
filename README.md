# Nova-Script

Unified Novation controller scripting environment and custom performance controller.

Transform your Novation Launchpad + Launchkey hardware into a deeply integrated show-rig control surface — bridging Reaper, the Akai Force, and MIDI/OSC devices into one cohesive live performance system.

## Hardware Support

| Device | Status |
|--------|--------|
| Launchpad Mini MK1 | Primary target |
| Launchkey 49 MK2 | Secondary target |
| Launchpad Mini MK3 | Planned |
| Launchpad X | Planned |
| Launchpad Pro MK3 | Planned |
| Launchkey Mini MK3 | Planned |

## Quick Start

```bash
python -m nova-script
```
